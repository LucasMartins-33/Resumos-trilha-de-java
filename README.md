# Resumos-trilha-de-java

## 📖 Sobre os Arquivos

Os resumos foram feitos para facilitar o entendimento de diversos conteúdos e estão integralmente em formato **Markdown (`.md`)**. 

> **Aviso Importante:** Os resumos foram elaborados com o auxílio de Inteligência Artificial. Em caso de erros, informações incorretas ou desatualizadas, sinta-se à vontade para modificar os arquivos ou enviar sugestões de melhoria!

## 🗂️ Estrutura do Repositório

O repositório é segmentado por temas e cursos. Dentro do diretório de cada curso, você encontrará a seguinte organização:

- 📂 `resumos dos capitulos/`: Contém as notas de aula de cada módulo (com exceção dos capítulos focados apenas em instalação de ambiente).
- 📂 `Questões/`:
  - 📝 `Questões práticas/`: Exercícios de código, lógicas de programação e desafios.
  - 🧠 `Questões teóricas/`: Perguntas para fixação de conceitos e arquitetura.
